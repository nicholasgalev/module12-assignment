# Module 12 Assignment: Business Analytics Fundamentals and Applications
This repository contains my work for the Module 12 assignment in ISM2411 Python for Business. The assignment focuses on using Python, Pandas,
and Matplotlib to complete a business analytics report for GreenGrocer.

## Files Included
- 'module12-assignment' - Python program for analyzing sales, customer, and operational data and creating business recommendations

## What I Practiced
In this assignment, I practiced using Python for descriptive, diagnostic, predictive, and prescriptive business analytics. I worked with Pandas
DataFrames, summary statistics, grouped analysis, correlations, visualizations, simple forecasting, and business recommendations. I also practiced
turning data analysis results into an executive summary for decision-making.
